Lab 6: Hierarchical Data Visualization: Trees and Treemaps

This lab explores two approaches to hierarchical data visualization using GDP data: a node-link tree and a treemap.

Design Description

I used two different hierarchical visualizations to show the same GDP dataset. In the node-link tree, position and links are used to show the parent-child relationships between the world, continents, areas, and countries. GDP is encoded using node size because size provides an intuitive way to compare quantitative values, while GDP status is represented using color because it is categorical data. The node-link tree makes the hierarchical structure and depth especially clear.

In the treemap, GDP is encoded using rectangle area, allowing larger economies to occupy more visual space. Color is again used for GDP status so that the encoding remains consistent across both visualizations. Spatial containment and borders are used to show the continent and area groupings. Compared with the node-link tree, the treemap uses space more efficiently and makes GDP magnitude easier to compare, while the node-link tree makes the hierarchical relationships easier to follow.
