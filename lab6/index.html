Lab 6: Hierarchical Data Visualization: Trees and Treemaps

This lab explores two approaches to hierarchical data visualization using GDP data: a node-link tree and a treemap.

Design Description

I used two treemap visualizations to represent the same hierarchical GDP dataset. In both visualizations, rectangle area encodes GDP because area provides a direct way to compare quantitative magnitude. GDP status is represented using color because it is categorical data, while spatial containment and borders show the hierarchy from continent to area to country. I kept the same visual encodings in both treemaps so that the main difference between them is the segmentation strategy.

The Squarify layout creates more balanced rectangular shapes, which makes country GDP values easier to compare and leaves more space for labels. In contrast, the Dice layout divides the hierarchy into long vertical regions. This makes the spatial subdivision more visually distinct, but large economies such as the United States can occupy a very large portion of the layout and compress smaller countries into narrow regions. As a result, some labels cannot be displayed and must be accessed through the tooltip. This shows the trade-off between readability of individual values and the visual structure created by different treemap segmentation methods.
