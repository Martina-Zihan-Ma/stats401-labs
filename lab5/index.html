Lab 5: Interactive Network Visualization with D3

Dataset Description

This lab uses two datasets describing a transportation network. The station dataset contains 50 stations, with attributes including station ID, station name, district, daily passenger volume, and station type. Station types include local, transfer, and terminal stations.

The route dataset describes the direct connections between stations. Each route specifies a source station, a target station, travel time, and route type. Together, the two datasets form a network in which stations are represented as nodes and direct routes are represented as links.

Node-Link Visualization

I design the node-link diagram to represents each station as a node and each direct transit connection as a link. Stations are colored by district and sized according to daily passenger volume. Station type is distinguished using different node border colors. For the links, opacity represents travel time, with darker links indicating longer travel times, while different line patterns distinguish Metro, Express, and Shuttle routes.

Adjacency Matrix

The adjacency matrix provides an alternative view of the transit network. I use each row and column represents a station, and a filled cell indicates a direct route between two stations. Stations are grouped by district to make connections easier to compare. Cell color represents route type, while cell opacity represents travel time, with darker cells indicating longer travel times.

Design Choices and Network Analysis

·Node-Link Design

District: Node fill color
Reason: District is nominal data, so different colors help readers quickly distinguish and group stations from different districts.

Passenger Volume: Node size
Reason: Larger nodes represent higher passenger volume, making quantitative differences easy to compare visually.

Station Type: Node border color
Reason: Station type is also nominal data. Border color separates Local, Transfer, and Terminal stations without changing node shape, which keeps node size comparisons consistent.

Travel Time: Link width
Reason: Travel time is quantitative, so thicker links represent longer travel times. Width is easier to compare than opacity when route patterns are also used.

Route Type: Link pattern
Reason: Route type is nominal data, so different line patterns distinguish Metro, Express, and Shuttle routes without adding too many colors.

Dragging: Users can move stations to explore connections more clearly.
Tooltip: Hovering over stations or routes shows detailed information.
Hover Highlighting: The selected station and its connected routes remain visible while unrelated parts fade. So that the selected station stands out.

·Adjacency Matrix Design

Rows / Columns: Stations
Reason: Each row-column pair represents a possible connection between two stations.

Station Order: Grouped by district
Reason: Grouping stations by district makes within-district and cross-district connection patterns easier to compare.

Label Color: District
Reason: Label color helps readers quickly identify the district of each station.

Cell Presence: Direct route
Reason: A filled cell indicates that a direct connection exists between two stations.

Cell Color: Route type
Reason: Different colors distinguish Metro, Express, and Shuttle routes.

Cell Opacity: Travel time
Reason: Darker cells represent longer travel times.

Tooltip: Hovering over station labels shows station information, while hovering over filled cells shows route details. Hover Highlighting: The selected routes connection remain visible while unrelated parts fade. So that the selected stands out.

·Network Questions and Findings

1. Which stations appear central in the network?

This question is only partially supported by the node-link diagram. The layout intentionally groups stations by district to make geographic groups easier to compare, so spatial position does not directly represent network centrality. As a result, there is no single station that can be identified as the clear topological center simply from its position in the diagram.

2. Which districts are strongly connected?

This question is easier to answer using the adjacency matrix because the district-based ordering makes dense groups of connections easier to compare. The node-link diagram provides additional spatial context through district clustering. The strongest cross-district connection is between East and South, which contains the largest number of direct routes between a pair of districts.

3. What positions do Transfer and Terminal stations occupy in the network topology?

This question is only partially supported by the current design. Transfer and Terminal stations are distinguished by border color, but they are not spatially separated from other station types. Therefore, no strong or consistent topological position is immediately visible. Users can hover over individual stations to inspect their station type and number of connections.

4. Which stations have high passenger volume?

The node-link diagram answers this question well because passenger volume is directly encoded by node size. Larger circles represent stations with more daily passengers. Station 50 has the largest passenger volume in the dataset, with 9,850 daily passengers. The matrix does not directly encode passenger volume, so this comparison is much less visible there.

5. Which direct connections have the longest travel time?

Both visualizations support this question. In the node-link diagram, longer travel times appear as thicker links, while in the adjacency matrix they appear as darker cells. The longest direct connection is between Station 7 and Station 31, with a travel time of 16 minutes.

6. Are certain route types concentrated in particular parts of the network?

No strong spatial concentration of route types is immediately apparent. Route patterns in the node-link diagram and cell colors in the adjacency matrix show that Metro, Express, and Shuttle routes are distributed across multiple districts. Routes involving South contain slightly more Shuttle connections than the other route types, but the difference is not large enough to indicate a strong concentration.
